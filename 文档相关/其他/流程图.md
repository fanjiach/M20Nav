### 1. WebSocket服务器通信模块流程图
```mermaid
graph TD
    A["程序启动"] --> B["初始化WebSocket客户端"]
    B --> C["连接服务器：ws/wss://{IP}:{Port}/robot/{dog_id}"]
    C --> D{连接成功?}
    D -- 失败 --> E["触发重连（间隔1s→3s→5s→10s递增）"]
    E --> C
    D -- 成功 --> F["发送连接鉴权（dog_id+token）"]
    F --> G{鉴权通过?}
    G -- 失败 --> H["断开连接，记录错误日志，重试连接"]
    H --> C
    G -- 成功 --> I["启动3s心跳定时器，发送心跳消息（heartbeat）"]
    I --> J["监听服务器消息/本地上报消息"]
    J --> K{消息类型}
    K -- 心跳回执 --> L["更新心跳状态，重置超时计数器"]
    K -- 任务指令（task_push/pause/cancel） --> M["转发至任务管理模块"]
    K -- 版本校验（version_check） --> N["转发至版本同步模块"]
    K -- 遥控/返航（remote_control/return_home） --> O["转发至对应控制模块"]
    K -- 其他指令 --> P["分发至对应业务模块"]
    J --> Q{心跳回执超时?}
    Q -- 是（≥5s） --> R["标记通信异常，触发重连"]
    R --> C
    Q -- 否 --> J
    M/N/O/P --> S["生成响应/上报消息（带seq_id/timestamp）"]
    S --> T{消息是否为核心指令?}
    T -- 是（急停/遥控/返航） --> U["AES-128加密+MD5签名"]
    T -- 否 --> V["JSON格式化（大消息gzip压缩）"]
    U/V --> W["发送消息至服务器"]
    W --> X{发送成功?}
    X -- 失败 --> Y["重试发送（最多3次）"]
    Y -- 重试失败 --> Z["记录错误日志，标记消息待补发"]
    X -- 成功 --> AA["更新消息发送状态，记录日志"]
    Z --> AB["重连成功后，按seq_id补发离线消息"]
    AB --> W
    AA --> J
```

### 2. 任务管理模块流程图
```mermaid
graph TD
    A["接收服务器任务（task_push）"] --> B["校验消息完整性（seq_id去重）"]
    B --> C["任务入库（sqlite，记录task_id/优先级/执行时间等）"]
    C --> D["异步下载任务包（地图/路线文件）"]
    D --> E{下载成功?}
    E -- 失败 --> F["重试下载（最多3次）"]
    F -- 仍失败 --> G["上报任务失败，标记错误码3001"]
    E -- 成功 --> H["MD5校验文件（分段校验）"]
    H --> I{校验通过?}
    I -- 失败 --> J["删除损坏文件，重试下载（最多3次）"]
    J -- 仍失败 --> G
    I -- 成功 --> K["解压文件，替换导航地图"]
    K --> L["解析路线JSON，生成路径点队列"]
    L --> M["预校验路径点合法性（坐标/路段ID）"]
    M --> N{校验通过?}
    N -- 失败 --> O["上报任务解析失败，错误码3005"]
    N -- 成功 --> P["定时触发任务（到达execute_time）"]
    P --> Q["前置校验（版本/时间/机器狗/网络状态）"]
    Q --> R{校验通过?}
    R -- 失败 --> S["暂停任务，上报校验失败原因"]
    R -- 成功 --> T["遍历后续4个路径点，提取路段ID"]
    T --> U["请求服务器校验路段占用状态（section_check）"]
    U --> V{路段未占用?}
    V -- 否 --> W["等待（1s轮询，最多30s）"]
    W -- 超时 --> X["触发Level2异常，上报错误码3001"]
    W -- 未超时 --> U
    V -- 是 --> Y["标记路段占用（dog_id+时间戳），下发导航指令"]
    Y --> Z["执行路径点导航，实时上报执行进度"]
    Z --> AA{路径点执行完成?}
    AA -- 是 --> BB["释放当前路段占用，执行下一个路径点"]
    BB --> T
    AA -- 否 --> CC{接收暂停/取消指令?}
    CC -- 是 --> DD["停止当前路径点，释放路段占用，上报暂停/取消状态"]
    CC -- 否 --> EE{执行异常?}
    EE -- 是 --> FF["触发异常处理模块，记录错误日志"]
    FF --> GG{异常可恢复?}
    GG -- 是 --> Z
    GG -- 否 --> HH["上报任务失败，标记断点，结束任务"]
    EE -- 否 --> Z
    AB["任务全部完成"] --> AC["上报任务结果（result_upload），更新任务状态"]
```


### 4. 视频处理模块流程图
```mermaid
graph TD
    A["程序启动"] --> B["初始化摄像头（前置/全景），OpenCV读取实时流"]
    B --> C{摄像头可用?}

    C -- 是 --> E["启动环形缓存：存储最近1分钟视频帧（内存/磁盘）"]

    G --> H{异常类型}
    H -- 机器狗报错 --> I["切片：前10s+后20s视频，高压缩比（画质优先）"]
    H -- 导航失败 --> J["切片：前15s+后15s视频，高压缩比（画质优先）"]
    H -- 视觉识别异常 --> K["切片：前5s+后10s视频，平衡压缩"]
    H -- 手动触发 --> L["切片：前30s+后30s视频，低压缩比（速度优先）"]
    I/J/K/L --> M["生成缩略图（320x240）+完整视频文件"]
    M --> N["异步上传缩略图至服务器（HTTPS）"]
    N --> O["上传完整视频（断点续传，超时30s）"]
    O --> P{上传成功?}
    P -- 否 --> Q["重试上传（最多3次）"]
    Q -- 仍失败 --> R["记录错误日志，错误码4099"]
    P -- 是 --> S["通知服务器校验视频MD5"]
    S --> T{校验通过?}
    T -- 是 --> U["删除本地临时文件，记录上传日志"]
    T -- 否 --> V["重新上传视频（最多1次）"]
    V --> O
    U --> W["继续采集视频流，重置缓存"]
```
